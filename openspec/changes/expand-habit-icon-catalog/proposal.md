## Why

The current habit editor offers only twelve icons, which makes distinct habits look repetitive and leaves common areas such as health, rest, creativity, work, and home without a fitting visual. A broader but organized catalog will make habits easier to identify without making the mobile editor cumbersome.

## What Changes

- Expand the controlled Lucide icon catalog from 12 to roughly 40 useful habit-oriented choices.
- Organize icon choices into clear categories in the habit editor.
- Preserve all existing icon identifiers and fallback behavior so current habits and backups remain compatible.
- Add coverage for catalog identifiers, categories, labels, and validation.

## Capabilities

### New Capabilities

- `organized-habit-icons`: Provides a larger, categorized, accessible icon catalog for creating and editing habits.

### Modified Capabilities

None.

## Impact

The change affects the habit icon type, Lucide component catalog, habit editor markup and styles, and catalog tests. It adds no dependency, Firestore migration, authentication change, or deployment change.
