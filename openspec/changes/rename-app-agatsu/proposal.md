## Why

The provisional Ritmo name does not express the intended identity as strongly as Agatsu, a concise name associated with self-mastery and progress over oneself. The application should present one consistent Agatsu brand everywhere users encounter or install it.

## What Changes

- Rename all user-facing application identity from Ritmo to Agatsu.
- Replace the letter-R loading and header marks with an Agatsu letter-A mark.
- Update the installable PWA name, page metadata, icon artwork, backup filenames, Markdown report heading, version footer, and accessible labels.
- Keep the GitHub Pages URL, Firebase project, IndexedDB database name, local theme key, and JSON backup discriminator unchanged to preserve existing data and links.

## Capabilities

### New Capabilities

- `brand-identity`: Defines the consistent Agatsu name and visual identity while preserving compatibility identifiers.

### Modified Capabilities

None.

## Impact

The change affects frontend copy, HTML metadata, the web app manifest, SVG icon, backup presentation, documentation, and tests for visible branding. It does not alter the data schema, cloud synchronization, authentication, deployment URL, or dependencies.
